# Выгрузка dumskaya-design.com с Weblium

Скрипт сохраняет сайт перед переездом с Weblium на свой сервер:

- **все адреса страниц** на трёх языках (ru / ua / en) и соответствие между ними — чтобы на новом сайте сохранить URL, которые уже в индексе Google;
- **все картинки в оригинальном качестве** (файлы, загруженные в Weblium);
- **тексты русской версии** — по файлу `content.md` на каждую страницу, с картинками в том же порядке;
- исходный HTML всех страниц всех языков как резервную копию.

## Запуск на сервере (Ubuntu)

```bash
git clone https://github.com/SergiyTymoshenko/dumskaya-site-export.git
cd dumskaya-site-export
apt install -y tmux
tmux new -s export
bash run.sh
```

`run.sh` сам поставит Python-зависимости в папку `.venv` и запустит выгрузку.
Займёт примерно 15–40 минут, картинок около 3 ГБ.

- Если SSH отвалился — подключитесь снова и выполните `tmux attach -t export`.
- Если выгрузка прервалась — просто запустите `bash run.sh` ещё раз: скачанное сохранится, докачается только недостающее.
- Другая папка для результата: `OUT=/root/site-backup bash run.sh`.

## Что получится в `~/dumskaya-export`

| Файл / папка | Что внутри |
|---|---|
| `report.txt` | Итог: сколько страниц и картинок, что не скачалось, у каких страниц нет перевода |
| `url_map.csv` | Одна строка на страницу: её адреса на ru / ua / en |
| `urls.csv` | Все адреса: код ответа, редиректы, title, description, h1, canonical |
| `images/` | Оригиналы картинок (`images/shop/` — товары магазина) |
| `images.csv` | По каждой картинке: размер, alt-тексты на трёх языках, на каких страницах стоит |
| `pages/ru/<адрес>/content.md` | Текст русской страницы с картинками по порядку |
| `pages/{ru,ua,en}/<адрес>/page.html` | Исходный HTML страницы |
| `site/` | Меню, подвал, sitemap, robots.txt, favicon, список всех рабочих адресов |

## Дополнительные параметры

```bash
bash run.sh --skip-images          # только адреса и тексты, без картинок (быстрая проверка)
bash run.sh --content-langs ru,ua,en   # content.md для всех языков, а не только русского
bash run.sh --image-workers 3      # медленнее, если сервер Weblium начнёт отвечать ошибками
```
